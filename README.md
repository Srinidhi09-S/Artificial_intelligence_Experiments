# Artificial_intelligence_Experiments
Learning Artificial Intelligence through hands-on Python experiments. Implementing algorithms and exploring intelligent solutions. Turning theoretical concepts into practical coding experience. 🚀🤖

## 📌 Project Overview

This repository contains **16 Artificial Intelligence (AI) laboratory experiments implemented using Python**. The experiments demonstrate fundamental AI concepts, problem-solving techniques, search algorithms, constraint satisfaction, logical reasoning, game-tree search, and artificial neural networks.

The project provides practical examples of how AI algorithms can solve problems such as route planning, state-space exploration, decision-making, logical inference, and classification.

Each experiment includes the problem statement, Python program, output, and result.

## 🎯 Objectives

- Understand the fundamental concepts of Artificial Intelligence.
- Implement AI search algorithms using Python.
- Solve state-space search and constraint satisfaction problems.
- Explore game-tree search and decision-making algorithms.
- Apply logical reasoning techniques to knowledge-based systems.
- Implement artificial neural networks for classification tasks.
- Understand algorithm execution through program outputs.

## 🧪 Experiments Included

| Experiment | Topic | Description |
|---|---|---|
| 1 | Breadth-First Search (BFS) | Finds the shortest route in an unweighted hospital navigation graph. |
| 2 | Depth-First Search (DFS) | Explores task dependencies and determines whether a target is reachable. |
| 3 | Water Jug Problem | Uses state-space search and BFS to measure a target quantity of water. |
| 4 | A* Search Algorithm | Finds a minimum-cost route using path costs and heuristic estimates. |
| 5 | Eight Queens Problem | Uses backtracking to place eight queens without conflicts on a chessboard. |
| 6 | Map Colouring CSP | Assigns colours to map regions while satisfying neighbouring-region constraints. |
| 7 | Minimax Algorithm | Selects a move by evaluating utility values in a game tree. |
| 8 | Alpha-Beta Pruning | Reduces game-tree search by skipping branches that cannot affect the decision. |
| 9 | Forward Chaining | Infers medical appointment eligibility from facts and logical rules. |
| 10 | Forward Chaining for Priority Consultation | Applies logical rules to infer respiratory symptoms, suspected infection, and consultation priority. |
| 11 | Resolution Refutation | Uses logical resolution to prove a conclusion through contradiction. |
| 12 | Family Relationship Reasoning | Uses logical facts and rules to determine family relationships. |
| 13 | Pattern Matching | Matches symptoms against predefined patterns to generate guidance. |
| 14 | Artificial Neural Network – Breast Cancer Classification | Uses a neural network to classify breast cancer data. |
| 15 | Handwritten Digit Recognition | Demonstrates an artificial neural network approach to handwritten digit classification. |
| 16 | Perceptron – Breast Cancer Classification | Uses a perceptron-based model for breast cancer classification. |

## 📚 Concepts Demonstrated

### 1. Search Algorithms
BFS, DFS, and A* search are used to explore states, determine reachability, and find routes through graphs.

### 2. State-Space Search
The Water Jug Problem demonstrates how states, legal actions, goal testing, and repeated-state detection can be used to solve a problem systematically.

### 3. Constraint Satisfaction
The Eight Queens and Map Colouring experiments demonstrate how constraints and backtracking can be used to find valid assignments.

### 4. Game-Tree Search
Minimax evaluates possible moves, while Alpha-Beta Pruning reduces unnecessary exploration without changing the minimax decision.

### 5. Knowledge Representation and Logical Reasoning
Forward Chaining, Resolution Refutation, and Family Relationship Reasoning demonstrate how facts and rules can be used to derive conclusions.

### 6. Pattern Matching
The pattern-matching experiment demonstrates how predefined symptom patterns can be compared with input information to generate guidance.

### 7. Neural Networks and Classification
The final experiments demonstrate neural-network and perceptron approaches to classification, including breast cancer data and handwritten digit recognition.
